# Fonts

`minecraft-regular.otf` and `minecraft-bold.otf`: "Minecraft Font" by JDGraphics (Jacob Debono),
from https://www.fontspace.com/minecraft-font-f28180. Listed there as Public Domain; the font files
themselves say "Free for Commercial Use". Not an official Mojang or Microsoft font.

`jetbrains-mono-regular.woff2` and `jetbrains-mono-bold.woff2`: JetBrains Mono (Latin subset, from
@fontsource/jetbrains-mono 5.0.0), SIL Open Font License 1.1, see `JETBRAINS-MONO-OFL.txt`. Used for
seeds and coordinates, and for every digit on the page so numbers stay readable.

`jetbrains-mono-regular.woff` is the same font in WOFF format, used only as the source for the
TrueType copies in `src/lib/exports/pdf-fonts/` (PDF downloads), made by `scripts/make-pdf-fonts.py`.
